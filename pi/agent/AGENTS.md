# Pi Global Agent Instructions

This file provides global instructions for Pi Coding Agent sessions.

## Required Tools (MUST)

These are hard requirements for every agent (Pi and others), not preferences. Canonical shared rule: `claude/rules/required-tools.md`. Do not use the legacy alternatives when the required tool is available.

- MUST use `fd` for file and directory discovery. Do NOT use `find`. Examples: `fd PATTERN`, `fd -e ts`, `fd -t f PATTERN`, `fd -H -I PATTERN`. Exception: POSIX-only environments where `fd` is unavailable.
- MUST use `rg` for text/code search. Do NOT use recursive `grep`.
- MUST use `jq` / `yq` for JSON/YAML inspection and transformation. Do NOT hand-parse with ad-hoc shell when `jq`/`yq` can do it.
- MUST use `ast-grep` for syntax-aware code search and codemods when plain text search may be unsafe.
- MUST use `sd` for simple literal/regex replacements in shell workflows. Use precise edit tools for small source-file edits.
- MUST use `taplo` for TOML formatting and validation.
- MUST use `shellcheck` and `shfmt` for shell script validation and formatting.
- MUST prefer non-interactive, machine-readable commands in automated agent workflows. Do NOT use interactive tools such as `fzf` unless the user explicitly requests them.
- MUST NOT re-read the same vendor bundle (`node_modules/**/dist/*.mjs` 等) or large file across multiple turns in one session; once read, note the relevant API/lines and reuse that instead of reading again. Re-reads compound conversation history and inflate cached input tokens on every subsequent request.

## AI Agent Routing

- **Model budget**: Fugu（Sakana）ペアは `fugu-max`（base）と `fugu-ultra-v2.0`（ultra）。`auto-fugu-model.ts` が Fugu ペア上でのみ base↔ultra を自動切替。`parallel-review` は5段階（**指定なしは auto** → Jev が深さを推定、失敗時 L3 フォールバック；**1..5 明示は常に優先**し、レベル選択の通信は不要）：L1/L2 は runtime caller + Muse（L2 は + Antigravity、dedupe 後 **1–2 / 2–3** reviewers）、L3 は旧 L2 相当（**計6** reviewers：Fugu Max を含む）、L4 は Codex/Opus max + Fugu Max、L5 は Fugu Ultra v2 を含む計6 reviewers。Jev は `route.review`（`resolve-model.sh --field id route.review`）と `OPEN_ROUTER_API_KEY` のみ。メイン Pi モデルは変えない。単体 `fugu-review` / `muse-review` はユーザー明示時のみ。長いセッションは `/new` または `/compact` で区切る。
- **Model IDs**: `pi/agent/model-roles.json` is the single source of truth. Skills and runners reference roles (`review.codex`, `review.claude`, `review.grok`, `review.fugu`, `review.muse`, `review.antigravity`, `route.review`, `route.fugu.base`, `route.fugu.ultra`, `impl.cursor`, `research.xai`), never literal model IDs. Resolve Pi roles with `~/.pi/agent/resolve-model.sh ROLE`; resolve Antigravity with `--field agy ROLE`; resolve the Cursor Agent role with `--field cursor ROLE`; list with `--list`; parallel-review tiers with `--review-level N` (`backend<TAB>model<TAB>initial<TAB>retry`); after editing the catalog run `--apply` to sync `enabledModels` into `settings.json`.
- **Implementation**: Use the `cursor-impl` skill (`/skill:cursor-impl` in Pi) to delegate actively to `cursor-agent` with role `impl.cursor` (resolve via `--field cursor`). Pi prepares the implementation prompt and validates the resulting diff, lint, and tests. Only trivial few-line edits may be done directly.
- **Browser automation**: Prefer `cmux-browser` for routine UI inspection, screenshots, navigation, and form interaction inside cmux when WKWebView capabilities are sufficient. Use Playwright only for Playwright E2E tests, Chromium/cross-browser behavior, viewport/device emulation, network mocking, tracing/video, or CDP-only features; if cmux is unavailable, Playwright may be used as the fallback. Every Playwright invocation must use an isolated session/profile and must not attach to the user's normal Chrome or reuse its profile unless explicitly requested; when using `playwright-cli`, use a named isolated session and close it in the same task. Canonical shared policy: `claude/rules/browser-automation.md`.
- **Web research**: Use the `firecrawl` skill (`/skill:firecrawl`; sourced from `skills/firecrawl-cli`) for general web search, scraping, URL fetches, docs crawling, and browser interaction. Use `firecrawl-agent` (`/skill:firecrawl-agent`) when structured JSON extraction or autonomous multi-page extraction is needed. These are linked into `~/.agents/skills/` via `scripts/build_env/list_shared_agent_skills.sh`.
- **Web research double-check**: Use `cross-research` (`/skill:cross-research`) for important research that needs verification; it runs Firecrawl, `agy` (Antigravity CLI, successor to Gemini CLI), and Grok X Search in parallel. Use `antigravity-research` (`/skill:antigravity-research`) only for agy-only broad summaries where facts are not treated as confirmed.
- **Review**: For plain 「レビューして」 (an actual review request in the turn—not a quote or discussion), load `parallel-review` and **execute immediately** after normal preflight: do not ask whether to use the skill or re-confirm Muse/Jev each run. One secret-filtered patch, isolated headless reviewers in parallel at a chosen tier (`reviewLevels` 1=lightest dynamic, 2=light dynamic, 3=standard, 4=deep, 5=deepest). **Unspecified level → auto** (Jev via OpenRouter Decisions API; fallback L3). **Explicit 1..5 always wins** without Jev. L1/L2 resolve the **runtime caller model** via Pi-exported `PI_PROVIDER`/`PI_MODEL`[/`PI_REASONING_LEVEL`] or `resolve-model.sh --current-model` (not `settings.defaultModel` or a fixed Codex id), plus Muse; L2 adds Antigravity. L3 matches the former L2 roster (Fugu Max, 6 reviewers). L4 raises Codex/Opus to max with Fugu Max. L5 matches the former L3 (Fugu Ultra v2). Muse Contributor uses submitted prompts/completions for training (not zero-data-retention). Jev sends the sanitized patch and, for auto only, optional secret-screened minimal routing context JSON (one routing Decisions operation per auto run—same shared payload for depth and chunk; up to 3 `http_error`-only HTTP retries with abortable default backoff or `Retry-After`, sharing one 15s total deadline; reviewers remain patch-only; `OPEN_ROUTER_API_KEY` required for auto). **Standing permission (personal setup)**: the review request in that turn also satisfies the generic external-send gate for scoped review API calls—submit secret-screened patches to **Jev** (one routing operation per auto run with the same Decisions payload, plus auto-only secret-screened minimal routing context JSON validated per `parallel-review` `SKILL.md` `schemaVersion: 1`; `http_error` retries only, max 3, abortable waits/`Retry-After`, one shared 15s total) and submit secret-screened **patch only** to **all selected reviewers including Muse Contributor training use**, without per-patch re-confirmation (including chunks and configured retries). Brief announcements are not approval gates. **Exceptions**: if credentials, customer data, or employer-confidential material may be present, stop and ask—standing permission does not override secret safeguards. If the user explicitly refuses, revokes, or restricts Muse/Jev submission, stop and ask—never silently omit Muse or switch providers. Do not broaden to unrelated API sends, email, messages, hooks, or arbitrary tasks. Pi reviewers run via `run_pi_review.sh`; Antigravity runs via `run_antigravity_review.sh` with the toolless global `patch-reviewer` agent. Tiers select model precision and fixed attempt budgets from `reviewTimeouts` (L1–L2 300/300s, L3 600/600s, L4–L5 600/900s initial/retry). Each reviewer is retried once after any failure (including timeout). All resolved reviewers for the tier run, including the caller when it appears as `current`. Pi child reviewers must disable skills/context to prevent recursive review spawning. Antigravity uses a dedicated toolless custom agent, empty invocation cwd, and disabled slash commands; agy has no Pi-equivalent `--no-session`/`--no-context` flag, may persist local conversations, and still reads global configuration—do not treat it as perfectly isolated. Install `~/.gemini/config/agents/patch-reviewer/agent.md` via setup scripts before use. Use a single-reviewer skill only when named (`codex-review`, `claude-review`, `grok-review`, `fugu-review`, `muse-review`). **`muse-review` standalone requires explicit Muse selection** with timeout 120s and `attempts=1`; standing training permission applies to user-requested reviews, subject to the same safety and permission exceptions above.
- **MCP integrations**: Use `mcp-delegate` (`/skill:mcp-delegate`) for Slack links and other hosted OAuth MCP workflows (Slack, Sentry, Notion, etc.). It delegates to Claude Sonnet with a connection gate and read-only hardening. Sentry issue workspace flow is still covered by `jj-workspace` (`/skill:jj-workspace`). Do not scrape private Slack URLs with Firecrawl/browser.
